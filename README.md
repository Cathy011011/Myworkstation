# 个人日程管理小助手 · v1.0

一个基于 WorkBuddy 资料库的**单文件日程管理网页应用**，数据真实存储在线上资料库数据表，多设备/多浏览器访问同一份数据，双向同步。

## 在线使用

**链接**：https://workbuddy.link/p/OxKRm0lpVdKq8P3qT30q74

用任何设备的浏览器打开即用。数据存在 WorkBuddy 资料库云端数据表，换设备打开数据都在。全新设备首次打开会自动同步云端已有数据。

## 功能模块

| 模块 | 说明 |
|---|---|
| 今日总览 | 首页，聚合各模块今日状态 |
| 日程 | 某天几点要做的具体事项 |
| 待办 | 没有固定时间点的任务清单 |
| 日程规划 | 本周/下周的阶段性安排 |
| 翻译 | 实时翻译 + 双语语料沉淀（需配置模型） |
| 问答 | 实时问答 + 知识沉淀（需配置模型） |
| 信息整理 | 摘录 + 结构化笔记 |

## 数据与同步机制

- 六张云端数据表：日程 / 待办 / 翻译 / 问答 / 日程规划 / 信息整理，各对应一个资料库表
- **本地即时生效 → 后台 diff 推送到云端**；点「刷新云端数据」/ 切回页面时拉取最新
- 顶栏状态徽章：●已同步 / ◐同步中 / ○异常（可点重试）/ ○离线
- 删除采用软删除 + 墓碑机制：删除立即生效、刷新不复活、云端确认后彻底清除
- 全新设备首次打开直接采纳云端数据（不显示示例数据）

## AI 翻译/问答（可选）

右上角「AI 设置」填中转站接口地址、模型、密钥即可。密钥只存本机浏览器 localStorage，不进页面代码、不进云端表。
