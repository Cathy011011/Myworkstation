# 第三节课 · WB 工作台 V2

基于资料库能力的集成式生活工作台。复刻线上页面《日常集·生活有迹可循》的视觉与容错架构，业务内容替换为六个新模块，数据存在线上资料库数据表里。

## 目录

```
01-需求/      需求规格说明书.md   功能定义、视觉契约、同步与容错契约
              字段字典.md         六表逐字段定义与迁移禁忌
02-原型/      demo.html           可交互演示版（本地假数据，增删改真实可用）
05-参考/      src/life-all-in-one.html   母版，只读，任何操作都不改它
06-交付/      改造完成后的在线版 HTML
07-脚本/      tables-schema.json         六表建表 schema，可据此重建
              browser-test.js            浏览器测试与回归脚本
版本归档/    v7/v8/v9 页面版本与版本索引
.workbuddy/memory/   项目记忆
```

## 六个模块

| 模块 | 定义 |
|---|---|
| 今日总览 | 默认首页，聚合六模块的今日状态 |
| 日程 | 某天几点要做的具体事项 |
| 待办 | 没有固定时间点的任务 |
| 翻译 | 实时翻译 + 双语语料沉淀 |
| 问答 | 实时问答 + 知识沉淀 |
| 日程规划 | 本周/下周的周期性阶段安排 |
| 信息整理 | 摘录 + 结构化笔记 |
